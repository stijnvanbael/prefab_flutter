- Custom actions: top-level functions annotated with `@EntityAction` appear on the generated detail screen (AppBar), list screen (AppBar) and each list item (trailing menu): the first two as icon buttons, the rest in an overflow menu, sorted by `order`, label and name. A wrong signature, an unknown entity or a non-literal argument fails the build with a readable error; promoted screens are skipped. New `prefab_actions` builder writes a summary only for files with `@EntityAction`, new `actions` feature module, and `appBarActions` (detail screen) and `itemActions` (list screen) extension points. (PF-44)
