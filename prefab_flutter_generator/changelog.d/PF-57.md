- Entities with a `@JobStatus` field show the state of the job in list items and in a banner on the detail screen, and refresh while the job runs: the list notifier polls with `PrefabJobPoller`, the detail provider becomes a `StreamProvider` built on `prefabPolledDetail` (unless the entity is `@Streaming`). The detail provider of such an entity changes from `FutureProvider` to `StreamProvider`, which is breaking for code that depends on its type. (PF-57)
- `@Update(path: ..., startsJob: true)` opens the detail screen of a list item after the operation ran. (PF-57)
- New extension points `detailScreen.beforeFields` and `listScreen.itemStatus`; `ListProviderArtifact.fetchCall`. (PF-57)
