## Description

A feature can be added by one agent in its own module, with few shared,
conflict-prone files and cheap, reliable tests. Development speed is the
goal: every later milestone builds on this structure.

Scope:
- Shared test harness and snapshot tests of generated output (PF-36)
- Architecture decision for the generator (PF-37)
- Generator core with per-artifact emission and proper import handling (PF-38)
- Migrate the existing features into feature modules (PF-39)
- Split the user guide into one page per topic (PF-40)
