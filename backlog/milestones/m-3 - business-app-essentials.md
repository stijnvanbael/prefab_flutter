## Description

The capabilities almost every business app needs, as found in the use-case
analysis in docs/vision.md and the reference apps.

Scope:
- Relations: reference fields with a lookup or picker and a display label;
  links to related lists
- Links from detail screens to nested child lists (PF-35)
- Annotation defaults: `@View()` without parameters (PF-21)
- More field types: money and decimals, quantities with units (kW, kWh, %),
  time ranges and schedules, lists of values, embedded value objects, files
  and images, rich text and markdown display
- Authentication (OIDC/JWT) and role-based visibility of screens, fields
  and actions
- Localisation of all generated strings and model labels
- Charts and dashboards: time-series and KPI widgets, a dashboard home
- App shell: navigation menu or rail, responsive master-detail layout for
  tablet, desktop and web
