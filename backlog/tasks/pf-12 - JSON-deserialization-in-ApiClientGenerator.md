## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The generated API client casts response.data directly to the entity type (e.g. response.data as Product), which crashes at runtime because Dio returns raw Map/List values. The ApiClientGenerator must detect a fromJson factory on the entity class (e.g. generated by json_serializable or freezed) and emit proper deserialization calls. Serialization of request bodies (create/update) must likewise call toJson() when available.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 ApiClientGenerator detects a fromJson(Map<String, dynamic>) factory on the entity class
- [ ] #2 List responses are deserialized via (response.data as List).map((e) => Entity.fromJson(e)).toList()
- [ ] #3 Single-object responses are deserialized via Entity.fromJson(response.data)
- [ ] #4 create() and update() serialize the entity body via entity.toJson() when the method is present
- [ ] #5 A clear build-time error is emitted when neither fromJson nor toJson is found and the entity is used in a read/write context
- [ ] #6 The example app entity uses json_serializable and the generated client deserializes responses correctly
<!-- AC:END -->
